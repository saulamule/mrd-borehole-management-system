Administrator update: The official editable register is data/boreholes.csv in the GitHub repository. Update the CSV and commit it to the main branch; GitHub Actions validates the register and republishes this dashboard. This website is read-only and contains no administrator password or GitHub token.

Data quality and use: Coordinates are plotted only when they fall within Fiji's broad geographic bounds. The script removes harmless internal spaces and degree symbols from numeric coordinate cells, but does not swap or guess coordinates. Records excluded from the map should be checked against the original field/GIS records. Confirm MRD approval before publishing this infrastructure register publicly.
